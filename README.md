### Why this approach fixes your problems:
1. **The Transparent Theme Hack:** I changed all your API themes to `transparent`. Instead of bulky boxes that clash with the background, your text and graphs now float seamlessly on the page, regardless of whether the user is in light mode or dark mode. 
2. **The "Details/Summary" Accordion:** By putting your heaviest widgets (the streak, the graph, the trophies) inside clickable `<details>` blocks disguised as `<kbd>` buttons, we prevent all those servers from hitting GitHub at the exact same millisecond when the page loads. This greatly reduces the chance of the SVGs failing to load.
3. **Typographical Reliability:** We removed the fragile `typing-svg` and `capsule-render` headers, replacing them with incredibly clean, bold markdown typography that will render instantly 100% of the time.
